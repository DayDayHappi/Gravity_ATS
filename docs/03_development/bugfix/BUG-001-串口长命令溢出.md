# BUG-001：串口长命令溢出丢字节

## Problem

`rtmp_video_start <url>` 等长命令下发后报 `command not found`，命令被截断。

## Root Cause

板端串口接收缓冲 `RT_SERIAL_RB_BUFSZ` 默认约 64B，长命令（45B 命令 + 77B 哨兵）一次性写入溢出丢字节。

## Solution

串口层统一分片写入：32 字节/片 + 片间 0.1s 延时。

## Verification

分片后命令完整下发，正常执行。
