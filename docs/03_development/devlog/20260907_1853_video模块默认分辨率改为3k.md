# video 模块默认分辨率改为 3k

## 日期
2026-09-07

## 变更来源
Document Agent Request 变更 2（TODO-CONFIRM 已由用户拍板）：「默认分辨率 3k」落在 **A. 模块配置默认** `ATS/config/modules/video.yaml`，`video.py` 代码 fallback 保持不动。

## 做了什么
模块默认录像分辨率 `video_resolution` 从 `"1080p"` 改为 `"3k"`（所有未 override 的场景 video task 默认 3k）。

- 3k 档经真机串口日志核实合法（板端回显 `w(2520)*h(1890) is 3k`）。
- `video.py` 未改动：`self.config.get("video_resolution", "1080p")` fallback 保留原样，仅由 yaml 提供值。

## 改了哪些文件
- `ATS/config/modules/video.yaml`（L2：`video_resolution: "1080p"` → `"3k"`）

## 如何验证
1. `grep -rn "video_resolution" ATS/config/` → 仅 `ATS/config/modules/video.yaml:2` 一处引用，无场景 override 冲突。

## 已知遗留
- EIS 参数本次不处理：`video.py` 只发 `cam_set video {resolution}`（不带 EIS 尾随参数）；历史命令 `cam_set video 3k 2` 中尾随 `2` 为独立 EIS（电子防抖）参数，如固件要求显式 EIS 需另立需求扩展。

## 文档影响（报告给 Document Agent，Code Agent 不改）
- 模块默认分辨率改为 3k，如需可同步 `docs/04_testing/test_case.md` 里 TC-007 的 `cam_set video` 描述（原描述 1080p）。
