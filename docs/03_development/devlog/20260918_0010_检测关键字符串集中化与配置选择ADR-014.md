# 20260918 检测关键字符串集中化与配置选择（ADR-014 源码实施）

## 任务（Task）

实施 ADR-014：把 video/rtmp 过程检测的固件关键字符串（`TT ERROR`）从内联代码集中到唯一来源文件，并通过 modules yaml 的 `detect_strings` 配置选择检测哪些串；`TTErrorMonitor` 泛化为 `StringHitMonitor`。

## 改动（Changed）

1. 新增 `ATS/drivers/detect_strings.py`：`DetectString`（key/pattern/label）+ `DETECT_STRINGS`（首条 `tt_error`，pattern `TT ERROR` 逐字不动）。
2. `ATS/modules/tt_error_monitor.py` → `ATS/modules/string_hit_monitor.py`：`TTErrorMonitor` → `StringHitMonitor`（构造接收一个/多个 `DetectString`，跨 chunk 截断前缀由字面 pattern 自动推导，命中展示文案统一 `{label} 命中 N 次：第 i 次…` 收敛进 `attach_to()`，新增 `build_monitor()` 公共入口）；旧文件删除。
3. `ATS/modules/video.py`：改读 `detect_strings` 配置，新增 `_attach_hit_listener`/`_detach_hit_listener`，删除 `_attach_tt_hits` 与 `TTErrorMonitor` 引用。
4. `ATS/modules/rtmp.py`：同上，改读 `detect_strings`，删除 `_attach_tt_hits`。
5. `ATS/config/modules/video.yaml`、`ATS/config/modules/rtmp.yaml`：加 `detect_strings: [tt_error]`。

## 文件（Files）

- 新增：`ATS/drivers/detect_strings.py`、`ATS/modules/string_hit_monitor.py`
- 删除：`ATS/modules/tt_error_monitor.py`
- 修改：`ATS/modules/video.py`、`ATS/modules/rtmp.py`、`ATS/config/modules/video.yaml`、`ATS/config/modules/rtmp.yaml`

## 原因（Reason）

ADR-014（Document Agent 2026-09-18 产出）要求检测串集中可扩展 + 可配置选择，消除 video/rtmp 两份 `_attach_tt_hits` 重复与 3 处内联硬编码，对齐 ADR-011 单一来源。行为不变：`tt_error` 的 pattern 与「命中不判 FAIL、只追加 detail」语义逐字一致；配置缺省由「默认检测」变为「默认不检测」（yaml 显式写 `[tt_error]` 保持原行为）。

## 验证（Verification）

- `python3 -m py_compile` 4 个改动文件通过。
- `python3 -m ATS.main --list-modules` / `--list-scenarios` 无 import 破坏。
- 单元测试：`_derive_splice_tails("TT ERROR")` 与历史 `_SPLICE_TAILS` 逐项一致；含正则元字符的 pattern 降级为空元组；基本命中、跨 chunk 截断还原、无污染、空配置返回 None、未知 key 抛 KeyError、多 DetectString、clear —— 全 PASS。
- 接线测试（mock console）：video/rtmp 挂载/摘除 listener、注入 `TT ERROR` 命中只标 detail 不判 FAIL、缺省不检测 —— 全 PASS。
- 配置加载：`load_module_config("video"/"rtmp")` 的 `detect_strings == ["tt_error"]`。

## 已知限制（Known limitation）

- 跨 chunk 前缀自动推导仅对纯字面串成立；未来新增含正则元字符的 pattern 需在 `detect_strings.py` 定义处显式标注（降级为不拼接），已写入文件 docstring 与 ADR-014。
- 未知 `detect_strings` key 抛 `KeyError`（显式报配置错误，不静默失效）。
