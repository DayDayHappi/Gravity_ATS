# 串口上下电控制模块实施（ADR-015）

## 问题描述

需要给 VX100 EVB 提供「断电重启」能力：PC 通过独立串口（115200）连接上下电控制模块，
板子电源线接该模块；脚本需要重启板子时发命令给控制模块执行下电/上电。本次交付能力封装
+ 探测 + 配置 + 生命周期挂接，不接「何时触发重启」（触发时机是另一独立模块，后续单独做）。

设计权威来源：`docs/02_design/decision_record/ADR-015-串口上下电控制模块.md`（Accepted）。

## 交付内容

### 1. 新建 ATS/drivers/power_commands.py（协议唯一来源，ADR-011）

只存协议字节/判据帧/超时，不 import IO/console/ctx/ftp/pyserial、不读 YAML：

- `POWER_ON_FRAME` / `POWER_OFF_FRAME`（PC→控制器上电/下电）
- `POWER_STATE_ON` / `POWER_STATE_OFF`（控制器→PC 状态 ON/OFF，探测判据）
- `POWER_FRAME_LEN`=4、`POWER_BAUDRATE`=115200
- `POWER_FRAME_TIMEOUT`/`POWER_DETECT_TIMEOUT`=3.0、`POWER_DETECT_READ_TIMEOUT`=0.5

帧格式（实测 `res/串口控制器log.txt`）：4 字节 hex，末字节 = 前三字节求和 & 0xFF，
不加换行；控制器响应约 1.0~1.1s，超时按实测放宽。

### 2. 新建 ATS/drivers/power_switch.py（能力接口，非测试模块）

- `PowerSwitch` 类：`power_on()` / `power_off()` / `reboot(delay)`（下电→延时→上电），
  长连接持有打开串口，`close()` 释放。
- `detect_power_switch(candidate_ports, baudrate, detect_timeout, reboot_delay)`：
  对每个候选串口按 115200 打开发上电帧，回 `POWER_STATE_ON` 者=控制器；命中后复用
  已打开句柄（不临时 open/close），非控制器关闭后试下一候选。
- 用 pyserial 直接操作独立串口（二进制帧），不走 SerialConsole；禁止反向 import 触发模块。

### 3. 修改 ATS/config/system.yaml

`serial` 段同级新增 `power_switch` 段：`enabled: false`（默认关零影响）、`baudrate: 115200`、
`reboot_delay: 3.0`（TODO-CONFIRM 待真机确定电容放电时间）。协议字节/判据/超时不进 yaml。

### 4. 挂接生命周期（ATS/core/scenario_manager.py）

- `@prepare_action("power_switch_init")`：enabled=false 直接 return；enabled=true 时候选端口
  = 全部可访问串口 减去 ctx.console.port（EVB），探测成功后存 `ctx.power_switch`。
- `@cleanup_action("power_switch_close")`：幂等，关闭 `ctx.power_switch` 串口并置 None。
- `normal.yaml` / `stress.yaml` 的 prepare 插 `power_switch_init`、cleanup 插 `power_switch_close`。

## 验证结果

- `py_compile` 通过（power_commands.py / power_switch.py / scenario_manager.py）。
- system.yaml 加载通过（schema 不破坏，power_switch 段默认 enabled=false）。
- 场景解析：normal/stress 均正确识别新动作名，prepare/cleanup 顺序正确。
- 离线验证 enabled=false 幂等零副作用（不探测、不 open）。
- 离线 fake-serial 模拟探测：正确区分控制器（回 POWER_STATE_ON）与乱码端口，长连接句柄保持打开；
  power_on/power_off 发帧正确、close 释放句柄。
- 校验和确认：四帧末字节均 = 前三字节求和 & 0xFF。

**待真机**：enabled=true 时需人工接两路串口验证控制器（115200）与 EVB（2000000）可靠区分防接反；
`reboot_delay` 默认值待真机确定。

## 经验沉淀

- 二进制协议帧 vs 文本交互协议（哨兵/回显）是两类串口模型，不能复用 SerialConsole，应独立封装
  并用 pyserial 直接收发。
- 探测判据选「主动命令的回包」（发上电帧回 ON 帧），既区分控制器又天然幂等（板子本就在线）。
- 协议字节/判据/超时全部沉淀 drivers 唯一来源，业务代码零内联（ADR-011），YAML 只存开关与硬件参数。
