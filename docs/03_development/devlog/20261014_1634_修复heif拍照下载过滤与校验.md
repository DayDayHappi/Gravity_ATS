# 修复 heif 拍照后不下载：下载过滤与校验纳入 .heic/.heif

## Date
2026-10-14 16:34

## Task
修复 heif 拍照后不下载到本地（Level 1 模块内部，无 ADR）：固件产出 `.heic`（日志 `...heic saved` / `Save Heif Successful`），下载过滤只认 `.jpg`，导致 heif 模式产物被过滤 → 走「未列出 jpg 辅助验证」降级 PASS、本地无 `.heic` 文件。

## Changed
仅改 `ATS/modules/photo.py`，两个点配套改（只改其一会导致 FAIL）：

1. `_list_jpgs`：扩展名过滤加入 `.heic` / `.heif`（大小写不敏感），docstring 说明固件产出 `.heic`。
2. `_verify_jpeg`：按扩展名分支校验——
   - `.heic` / `.heif` → HEIF（ISO BMFF）盒头校验：读前 12 字节，第 4~8 字节应为 `ftyp`；失败返回「HEIF 头校验失败」。
   - 其余（`.jpg`）→ 保持现有 `\xff\xd8\xff` JPEG 魔数校验不变。
3. 模块顶部新增 `_HEIF_FTYP = b"ftyp"` 常量（HEIF 顶盒 box type，位于前 4 字节 box size 之后）。
4. 文案顺带修正：成功消息「全部 N 张 jpg 校验通过」→「全部 N 张图片校验通过」；FAIL detail「含 N 个 jpg」→「含 N 张图片」。

## Files
- `ATS/modules/photo.py`

## Reason
heif 拍照固件实际产出 `.heic`（13~30KB），`.heic` 是 HEIF（ISO BMFF）格式，不能套 JPEG 魔数。若只把 `.heic` 纳入下载过滤而不改校验，`.heic` 会因 JPEG 头校验失败被误判 FAIL。二者必须配套改。

- 离线单测 `tests/test_photo_heif.py`（6 用例）：

  - `.heic`/`.heif` 走 HEIF 分支（校验通过含「HEIF」）；`.jpg` 走 JPEG 分支（含「JPEG」）。
  - 反例：`.heic` 内容非 HEIF（无 ftyp）→ 校验失败；`.jpg` 内容非 JPEG → 校验失败。
