# cam_run 命令族迁移（photo / video / rtmp 启动停止）

- **Date**：2026-11-10 15:58
- **Task**：按 Document Agent 任务单 `docs/03_development/archive/code_task_cam_run命令族迁移.md`（状态：已就绪）实施
- **分支**：`feat/windows_rebuild_app_arch`（基于 `feature/windows-cli`）
- **变更级别**：Level 1（仅 `drivers/*_commands.py` 协议常量值 + 注释；模块/时序/超时零改动）

## Change

把三组「开始 / 停止」串口命令由旧命令族（`dfs_*`、`rtmp_video_*`）迁移到固件新命令族 `cam_run *`。

### 最终生效的 `*_COMMAND`（Document Agent 同步文档依据）

```text
PHOTO_CAPTURE_COMMAND = "cam_run photo"
VIDEO_START_COMMAND   = "cam_run video start"
VIDEO_STOP_COMMAND    = "cam_run video stop"
RTMP_START_COMMAND    = "cam_run live start {url}"     # 保留 {url} 占位，模块侧 .format(url=...)
RTMP_STOP_COMMAND     = "cam_run live stop"
```

### 判据字符串是否变化

**无变化**，`*_EXPECT` 一律未改（用户 2026-11-10 确认新命令族仍输出原有业务完成串）：

```text
PHOTO_CAPTURE_EXPECT = r"Capture completed successfully."
VIDEO_START_EXPECT   = r"Record Start|f_index\s*="
VIDEO_STOP_EXPECT    = r"Video recording completed successfully."
VIDEO_CLEANUP_EXPECT = r"Save Video|Please start|recording completed"
RTMP_START_EXPECT    = r"publish ready|Push Start"
RTMP_STOP_EXPECT     = r"Push Stop|Stop requested"
```

判定链路零改动；超时值（`*_TIMEOUT`）、时序、`sleep`、重试次数均未调整。

### 本次明确未改（用户已拍板）

- `cam_set photo {mode}` / `cam_set video <组合>` / `cam_set live bitrate {bitrate}` 保持原字面量；
- `cam_set` 判据加固（静默失败 → 假 PASS 风险）本次不做，风险留 `docs/05_handoff/known_issue.md`；
- `ftp_server`、eMMC / WiFi 命令。

## Reason

固件命令族已从 `dfs_*` / `rtmp_video_*` 迁移到 `cam_run *`，旧命令不再可用。按 ADR-011，命令字面量只应存在于 `drivers/<module>_commands.py`，故仅改常量值即可让全部模块生效。
