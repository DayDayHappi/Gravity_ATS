# 新增单元测试场景 photo_only（仅拍照，不下载）

## Date
2026-11-19 18:24

## Task
新增单元测试场景 `ATS/config/scenarios/photo_only.yaml`：**仅拍照、不做 FTP 下载**，用于真机快速验证 `cam_set photo`（模式/size）+ `cam_run photo` + 存盘路径扫描链路（Level 1：纯配置，不改源码/接口）。

## Changed
- 新增 `ATS/config/scenarios/photo_only.yaml`：
  - `prepare` 仅 `serial_init` + `preclean`（去 `wifi_connect`/`ftp_ready`/`preview_start`，全程不碰网络/FTP/preview）。
  - `tasks` 仅 1 个 `photo` task，`override.ftp_download: false`（走纯拍摄分支：等 `Capture completed successfully.` 即 PASS，仅扫 `/emmc/PIC/<ts>/` 作落盘证据，不做 JPEG 头/大小校验）。
  - `loop.enable: false`（单轮跑完即止）。
  - `cleanup` 仅 `close_serial`。
  - `photo_modes` 为结构化映射列表（`{mode, size}`），**mode × size 全枚举 42 条**（mode-major：auto→single→mfnr→hdr→fcov→heif，每 mode 内 size 12m→8m→w8m→3m→1080p→720p→480p），与 ADR-018 一致。

参考 `no_network.yaml` 的「无网络 prepare + ftp_download:false」模式，但只保留 photo。

## Files
- `ATS/config/scenarios/photo_only.yaml`（新增）

## Reason
需要一条最小拍照链路场景：不依赖 WiFi/FTP/preview，单轮快速冒烟 `cam_set photo`/`cam_run photo` 链路。既有场景（normal/stress/no_network 等）都含 video/rtmp/emmc 或整轮 loop，粒度过大。

## Verification
- `yaml.safe_load` 解析通过；`name=photo_only`、`prepare=['serial_init','preclean']`、`tasks=['photo']`、`cleanup=['close_serial']`。
- `photo_modes` 元素数 = **42**；集合 = mode(6) × size(7) 全排列（无缺/无重/无 extra），顺序 mode-major 正确；每元素含 `mode`+`size` 且不含 `num`。
- `python -m ATS.main --list-scenarios` 输出含 `photo_only`。
- `python -m ATS.main --scenario photo_only --dry-run` → **exit 0**（配置与依赖校验通过，`[photo_only] tasks: ['photo']`）。
- 未跑真机（离线仅验证场景解析与配置契约）。

## Known limitation
- `photo_modes` 用 `{mode, size}` 结构化形式，**取决于 ADR-018 接口落地**：
  - 当前工作区有一版**未提交**的含 `num` 实现（`PhotoParams(mode, size=None, num=None)`），本场景所有元素都带 `mode`+`size`（无 `num`），与「有/无 num」两版**均兼容**（size 可选/必填都满足）。
  - 若 ADR-018 修订版（size 必填、无 num）实施后，本场景**无需改动**。
- 若真机某 `mode × size` 组合不被固件接受（报 Usage/not supported），当前 `cam_set` 判据为纯负向、可能不 FAIL（既有观测性缺口，见 `known_issue.md`）——真机跑此场景时需人工看 `serial.log` 回显 `photo: mode=... size=... fps=...` 确认；建议逐条比对 42 条 TX 回显。
- 42 条同目录跑（每组合一个 timeStamp 子目录），单轮耗时随组合数增长；如需分档逐步验证，可临时删减 `photo_modes` 元素。
