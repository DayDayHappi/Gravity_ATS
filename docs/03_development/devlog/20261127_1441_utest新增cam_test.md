## Changed
- 新增 `ATS/drivers/utest/cam_commands.py`：`TESTCASE = "cam_test"` +
  `BUSINESS_RES`（ADR-011 唯一来源，只存常量）。
  强校验正则（回引 `\1`，val == expect）：
  ```python
  r"sif0\s+\[0xf9000254\]=(0x[0-9a-fA-F]+)\s+\(expect\s+\1\)\s+ok"
  ```
  锚定 `sif0 [0xf9000254]=<val> (expect <val>) ok`；地址与期望值
  `0x0000030c` 为该 case 固定值（用户拍板）。
- 新增 `ATS/modules/utest/cam.py`：`@register("utest_cam")` 的 `CamModule`，
  继承 `UtestCaseModule`，仅设置 `testcase` / `business_res`（照 `efuse.py`）。
- 改 `ATS/modules/utest/__init__.py`：追加 `from . import cam`。
- 改 `ATS/core/config.py` `_MODULE_FILE_MAP`：追加 `"utest_cam": "utest"`，注释 8→9。
- 改 `ATS/drivers/utest/_common.py` `UTEST_TESTCASES`：追加 `"cam_test": 20.0`
  （固件 run timeout 10s 组 → 脚本 20s，实测约 7.1s 留余量）。
- 改 `ATS/config/scenarios/utest.yaml`：tasks **末尾追加** `- module: utest_cam`
  （用户拍板放最后一条）；顶部注释「8 项」→「9 项」。
- 新增 `tests/test_utest_cam_commands.py`：7 例离线单测。
