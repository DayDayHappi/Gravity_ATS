## Date / Task

- 日期：2026-09-16
- 任务：拍照/录像下载行为改为可配置（`ftp_download`，默认 true），新增「无网络」场景
- 需求来源：`docs/03_development/archive/新增需求_下载行为可配置与无网络场景.md`（关键决策已拍板，见 §8）

## Changed

1. `ATS/modules/photo.py`：`run()` 读 `ftp_download`（默认 true）；false 时不 ensure_ftp、
   不建 tmp_dir、不列目录/下载/校验，`_test_one` 走纯拍摄分支——等 `Capture completed
   successfully.` 后扫描 `/emmc/PIC/<ts>/` 作落盘证据，即 PASS。
2. `ATS/modules/video.py`：`_run_once` 读 `ftp_download`（默认 true）；false 时走新增
   `_run_no_ftp()`——设置 size → 开始录像（Record Start|f_index）→ 停止录像
   （Video recording completed successfully.）→ 扫描 `/emmc/VIDEO/<dir>/Video_*.h265`
   作证据，即 PASS；不 size/不下载；TT ERROR 检测保留（命中只标 detail，不判 FAIL）。
3. `ATS/config/modules/photo.yaml` / `video.yaml`：新增 `ftp_download: true`（默认，行为与现状一致）。
4. `ATS/config/scenarios/no_network.yaml`（新增）：无网络场景，preview.enabled=false，
   prepare 仅 `serial_init` + `preclean`（去掉 wifi_connect/ftp_ready/preview_start），
   tasks 为 `emmc` + `photo`（override.ftp_download=false）+ `video`（override.ftp_download=false），
   去掉 rtmp/video_integrity；cleanup 为 `stop_stream` + `close_serial`。

## Reason

测试场景按网络环境分两类：有网络拍完即 FTP 下载校验（现状不变），无网络完全不依赖
WiFi/FTP。下载行为由场景层 override 决定，模块默认 true 向后兼容。

## Verification

- `python3 -m py_compile ATS/modules/photo.py ATS/modules/video.py` → OK
- `--list-scenarios` 出现 `no_network`；`--list-modules` 不变（仍 9 个）
- `load_scenario('no_network')` 结构正确（prepare/tasks override/preview.enabled=false）
- `load_module_config('photo'/'video')` 默认 `ftp_download=True`
- 离线单测（mock console，ctx 不设 ftp_client/evb_ip）：photo/video `ftp_download=false`
  分支均 PASS，且 photo 全程未触发任何 FTP 命令；video 输出录像文件证据路径。
