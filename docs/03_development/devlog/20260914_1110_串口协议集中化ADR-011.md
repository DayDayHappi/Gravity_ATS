# 串口协议集中化（ADR-011 实施）

- **日期**：2026-09-14
- **任务**：将各模块散落的固件协议字符串（命令 / 判据 / 超时 / 正则 / 路径）集中迁移到 `ATS/drivers/<module>_commands.py`，作为唯一维护位置。

## 问题描述

photo / rtmp / ftp / wifi / emmc 等模块的固件协议字符串（`cam_set photo ...`、`rtmp_video_start`、`ftp_server`、`wifi scan`、心跳正则 `f_index`、超时值、`/emmc` 路径等）原先内联在 `ATS/modules/*.py` 与 `ATS/core/scenario_manager.py` 中，多处重复、易漂移。ADR-011 决定把这些协议定义集中到 `ATS/drivers/<module>_commands.py`。

## 修复内容

### 新增协议定义文件（5 个）

- `ATS/drivers/photo_commands.py`：`PHOTO_SET_COMMAND` / `PHOTO_CAPTURE_COMMAND` / `PHOTO_CAPTURE_EXPECT` / `PHOTO_SET_TIMEOUT` / `PHOTO_CAPTURE_TIMEOUT` / `_PIC_DIR`，以及 `PHOTO_MODES`（MappingProxyType，auto/single/mfnr/hdr_0~3，带 TODO-CONFIRM 注释）。
- `ATS/drivers/rtmp_commands.py`：`RTMP_START_COMMAND` / `RTMP_STOP_COMMAND` / `RTMP_START_EXPECT` / `RTMP_STOP_EXPECT` / 各超时，及 `RTMP_HEARTBEAT_RE`（含窗口隔离注释）。
- `ATS/drivers/ftp_commands.py`：`FTP_START_COMMAND` / `FTP_START_EXPECT` / `FTP_GO_WRONG_RE` / `FTP_START_TIMEOUT` / `_EMMC_DIR`。
- `ATS/drivers/wifi_commands.py`：`WIFI_IFCONFIG_COMMAND` / `WIFI_SCAN_COMMAND` / `WIFI_JOIN_COMMAND` / `WIFI_SCAN_HEADER_RE` / `WIFI_SCAN_ROW_RE` / `WIFI_GOT_IP_RE` / `WIFI_IFCONFIG_IP_RE` 及各超时。

## 原则

- **纯移动，不改协议语义**：所有命令/正则/超时/路径值与迁移前逐字等价（git diff 可核对），仅发现 `cd /` 无现成常量才新增 `EMMC_CD_ROOT_COMMAND`（值不变）。
- `*_commands.py` 只存协议常量，无 IO / 编排，不导入 console / ftp / ctx。

## 验证结果

- `python3 -m py_compile`：全部 12 个改动文件通过。
- `--list-modules`：9 个模块正常列出；`--list-scenarios`：8 个场景正常列出。
- `git diff`：逐字核对各迁移值等价，无值变化。
- grep 全仓内联协议字符串：业务侧（modules/core）无残留，仅 `*_commands.py` 常量定义本体、yaml/python 注释、`ftp_server_started` 属性名命中。

## 经验沉淀

- 协议定义集中到 `drivers/<module>_commands.py` 后，固件日志格式或命令变更只需改一处。
- 迁移时先全量 grep 内联字符串，再逐引用替换，最后 grep 验证无残留，可保证「纯移动」。
