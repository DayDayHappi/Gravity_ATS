# ADR-007：模块红线（模块只做一次动作，循环由 Scenario/Runner 驱动）

## Background

模块需要可复用；压测 / 老化通过组合模块 + 循环参数实现，而非在模块内写死循环。

## Problem

模块若感知场景类型、或内部写 for 循环重复，会破坏职责边界，加新场景就得改模块代码。

## Decision

- **模块只实现一次测试动作 + 参数接口**。
- 循环 / 重复 / 持续时间一律由 Scenario + Runner 驱动（task.repeat / task.duration / scenario.loop）。
- 模块内**不得出现 for 循环重复**、**不得感知场景类型**。

## Alternative

模块内写循环：当前 stress/aging 已能通过 repeat/loop 实现，模块内循环属重复且破坏边界。

## Impact

所有模块，已写入代码注释（不可违反红线）。

## Status

Accepted
