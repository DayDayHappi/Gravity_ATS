# ADR-001：串口命令结束判定采用哨兵机制

## Background

msh 提示符 `msh />` 会被后台日志 / 命令回显打碎粘连（实测 `msh />[32m...`、`msh />wifi scan`、`msh />msh />`），无法靠「等提示符」判定命令已返回。

## Problem

需要一种可靠方式判定「命令已执行完毕」，同时区分「命令返回」与「业务完成」。

## Decision

- **同步命令**（ifconfig / wifi scan / cd / cam_set）：发 `cmd` + 换行 + `echo "TOKEN"`，等**行首哨兵**定界，表示「命令已返回」。
- **异步命令**（wifi join / 拍照 / 录像 / rtmp 推流）：**只发 `cmd`、不发哨兵**，直接等业务正则（后台业务未完成时 shell 已返回，哨兵无意义）。
- 哨兵用**换行分隔**（msh 不支持 `;`），`echo` 必须带引号。
- 解析前一律剥离 ANSI。

## Alternative

- 纯等提示符 + 超时：提示符被打碎，不可靠。
- 纯超时：无定界，响应边界模糊。

## Impact

`core/serial_console` 核心机制；所有模块命令执行走此通道。

## Status

Accepted
