# devBugLog - 修改记录索引

本目录记录 ATS 脚本的所有修改（bug 修复、功能改进、重构等）。

## 规则

**每次对 ATS 代码的修改，都必须在本目录新建一个记录文档**，文件名格式：

```
<YYYYMMDD>_<HHMM>_<简短描述>.md
```

例如：`20260812_2302_修复连续运行emmc报错.md`

## 文档模板

每篇记录包含：

1. **问题描述**：现象、复现步骤、严重程度
2. **根因分析**：为什么会这样
3. **修复内容**：改了哪些文件、具体改动（diff 形式）
4. **验证结果**：修复后如何验证、结果数据
5. **还会再有吗**：是否彻底解决、有无残留风险
6. **经验沉淀**：可复用的排查思路或设计原则
